# Recommendation Sensitivity

EdgeIQ evaluates a fixed, verified-history forecast distribution at the exact offered line. An alternate line changes the probability without retraining the projection on that alternate offer. For whole-number discrete stats, the model allocates probability to a push; Over and Under are not complements.

The recommendation detail shows a bounded half-point adverse move and nearby hypothetical lines. Its 52% threshold is the research-screening threshold, not a paid-entry release gate. Shifted lines are **not** treated as available provider offers, and the display does not reprice provider payouts or assert calibrated probability at those hypothetical lines. A real entry still requires current offer, payout, calibration, and settlement checks.

Thin-history market-prior forecasts have no meaningful line sensitivity. They display an unavailable state instead of a synthetic curve. Existing immutable recommendation snapshots remain unchanged; new scans include the sensitivity object.
