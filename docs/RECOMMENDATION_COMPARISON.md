# Recommendation Comparison

On Today's Opportunity Board, select **Compare** on 2-5 recommendations, including offers from different providers. This selection is separate from **Send selected**, which still enforces the single-provider entry rule. Comparison is read-only and never places or changes an entry.

The table shows line, projection, model and calibrated probabilities, matching calibration sample count, data-quality score, forecast standard deviation, fragility, line movement, model track record, freshness, provider availability, portfolio overlap, and EdgeIQ Score. Missing values remain unavailable. Model track records load only after opening the comparison and are tied to the selected model version, sport, stat, provider, and direction; truncated records are marked incomplete.

Users can sort by highest calibrated probability, lowest fragility, or highest **actual EdgeIQ Score**. Missing ranking values sort last. The sort labels name the selected metric and do not declare a winning or profitable prop. Provider availability is an EdgeIQ eligibility snapshot, not a guarantee that the line remains on the provider app; recheck before paid use.
